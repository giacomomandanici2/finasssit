# Runbook: LLM 429 Too Many Requests

## Sintomo

- L'API risponde **HTTP 429** sulle route `/api/v1/agent/ask` o `/api/v1/rag/answer`
- Log JSON con `"level": "WARNING"` e messaggio `"Rate limit exceeded"`
- Header `Retry-After: <seconds>` nella risposta
- SlowAPI restituisce `{"detail": "Rate limit exceeded"}`

## Diagnosi

1. **Verificare il rate limit currente** — controllare `limiter._key_func` / default_limits in `app/core/slowrate.py`
2. **Identificare il client incriminato** — cercare nei log il campo `user_id` o `request.remote_addr` associato al 429
3. **Controllare se è un attacco (burst against)** — guardare la frequenza: se un singolo utente supera 30 req/s (nginx) o 5 req/min (agent), è anomalo
4. **Controllare se è traffico legittimo** — integrazioni esterne, webhook o test automation che chiamano troppo velocemente

```bash
# Cerca 429 nei log recenti (JSON structured)
grep '"level": "WARNING"' /var/log/app/finassist.log | grep '429\|Rate limit' | tail -20
```

## Remediation

### Temporanea (subito)

```bash
# Se nginx sta limitando, aumentare il burst
# docker exec finassist-nginx nginx -s reload
# (dopo aver modificato nginx.conf)
limit_req zone=api_limit burst=50 nodelay;
```

```bash
# Se SlowAPI sta limitando, aumentare il limite specifico
# in app/core/slowrate.py modificare la decoratore @limiter.limit("10/minute")
# poi ricostruire e rilassare
```

### Definitiva

- Aumentare i limiti SlowAPI per le route coinvolte (agent: `"10/minute"`, rag: `"20/minute"`)
- Se il traffico è costantemente sopra la soglia, aggiungere più worker gunicorn
- Se l'Azure OpenAI ha un TPM (token per minute) troppo basso, richiedere un upgrade del deployment
- Implementare caching per le risposte RAG se le query sono ripetitive

## Escalation

| Soglia | Azione |
|--------|--------|
| >10 429/min | Notifica al team Slack #alerts |
| >50 429/min | Page DevOps (PagerDuty) — potrebbe essere un attacco DDoS |
| Azure OpenAI 429 | Contattare Microsoft support per aumentare il quota TPM del deployment |

## Riferimenti

- `app/core/slowrate.py` — configurazione SlowAPI e limiti
- `nginx.conf` — `limit_req_zone` e `limit_req` per IP
- `app/api/agent.py` — decoratore `@limiter.limit("5/minute")`
- `app/api/rag.py` — decoratore `@limiter.limit("10/minute")`
- Dashboard Grafana: `Rate Limiting > 429 per route`
